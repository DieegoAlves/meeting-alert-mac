# F-050 — Eventos de dia inteiro disparam alertas à meia-noite

## F-050 | categoria: funcional | severidade: alta | status: fixed
- Tela: Sources/Scheduler/AlertPlanner.swift:26-41 — `candidates()` não filtra `event.isAllDay`
- Passos: 1) Sincronizar um calendário com um evento de dia inteiro (ex.: "Feriado", "Team Off Day") para amanhã. 2) `EventDTO.toCalendarEvent()` marca `isAllDay = true` e mapeia o início para meia-noite local (Sources/Sync/EventDTO.swift:79,133-139). 3) `AlertPlanner.candidates()` percorre o evento sem `if event.isAllDay { continue }` entre `isDeclined` e o loop de stages, gerando candidatos `.notify` (T-5) e `.overlay` (T-1).
- Esperado: Evento de dia inteiro NÃO dispara alerta (a história diz "every timed calendar event") — nenhum alarme à meia-noite.
- Observado: Para um all-day iniciando 2026-09-16T00:00 local, o planner arma `.notify` às 23:55 e `.overlay` (overlay cheia-tela) às 23:59 de 2026-09-15. Trecho (AlertPlanner.swift:32-39): `for stage in stages { ... let fireDate = ... event.start.addingTimeInterval(-TimeInterval(leadMin * 60)) ... }` — sem qualquer guarda de `isAllDay`. Usuário recebe overlay à meia-noite para feriados/aniversários/dias-livres.
- (resolvedor) Correção: status = fixed — added `if event.isAllDay { continue }` after the `isDeclined` guard in `AlertPlanner.candidates()` (line 32). All-day events are now skipped before stage iteration; no Core types changed.
