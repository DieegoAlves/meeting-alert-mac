# F-020 — Data races em CalendarSyncService (@unchecked Sendable, estado mutável sem sincronização)

## F-020 | categoria: funcional | severidade: alta | status: fixed
- Tela: `Sources/Sync/CalendarSyncService.swift:57` / `:90-95` / `:271-280` / `:42-43` + `Sources/App/AppDelegate.swift:80`
- Passos: 1) A rede reconecta → `NWPathMonitor.pathUpdateHandler` roda na fila `com.meetingalert.sync.network`. 2) Ao mesmo tempo o Mac acorda → `wakeObserver` roda na main. 3) Ambos chamam `triggerSync()`, que faz `currentSyncTask?.cancel(); currentSyncTask = Task { … }` sem lock.
- Esperado: acesso a `currentSyncTask` e a `preferences` serializado por uma única sincronização (a classe é `@unchecked Sendable`, linha 38, então a isolação é responsabilidade do autor).
- Observado: só `_syncState` é protegido (`stateQueue`, 47-52). `currentSyncTask` (57) é mutado concorrentemente da main e da fila de rede via `triggerSync()` (`currentSyncTask?.cancel(); currentSyncTask = Task { [weak self] in await self?.syncNow() }`, 90-95) → mutação de propriedade de classe entre threads = comportamento indefinido. `preferences` (42-43) é `var` de struct com o comentário `// Preferences are read at sync time; safe to update from any thread.` — falso: é escrito na main (`AppDelegate.swift:80`) e lido em tasks de fundo (`filterCalendars`:227, `setupBackgroundScheduler`:237) → leitura rasgada. **Impacto p/ usuário: reconexão de rede coincidindo com o wake pode travar o app ou disparar syncs duplicadas/vazadas em vez de sincronizar uma vez limpa.**
- (resolvedor) Correção [Auth/Sync worker]: FIXED no CalendarSyncService — `currentSyncTask` agora só é mutado sob `taskLock` (NSLock) em `triggerSync()`/`stop()`; `preferences` virou propriedade computada com backing `_preferences` serializado por `prefsQueue` (API pública `var preferences` inalterada, AppDelegate segue compilando); `backgroundScheduler` protegido por `schedulerLock`; `lastNetworkStatus` já é serial (só tocado na fila do NWPathMonitor). Zero mudança em Core. `swift build --target Sync` verde.
