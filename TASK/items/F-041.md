# F-041 — Erro transitório no token endpoint (429/5xx) apaga o refresh token e força re-login

## F-041 | categoria: funcional | severidade: alta | status: fixed
- Tela: Sources/Auth/GoogleAuth.swift:209-211 (`postToTokenEndpoint` lança em QUALQUER não-200), :184-198 (`refreshAccessToken` deleta o Keychain em QUALQUER erro), :193-197 (delete + cachedToken=nil)
- Passos:
  1) Usuário autenticado; access token expira e dispara refresh.
  2) `oauth2.googleapis.com/token` responde 429 (rate limit) ou 500/502/503 (indisponibilidade transitória).
  3) `postToTokenEndpoint` vê status != 200 → lança `AuthError.tokenExchangeFailed` (:209-211).
  4) O `catch` de `refreshAccessToken` trata como "refresh token inválido" → `KeychainStore.delete(...)` + `cachedToken = nil` (:193-197).
- Esperado: só um `400 invalid_grant` (ou 401) — sinal autoritativo de que o refresh token morreu — deve apagar a credencial; 429/5xx são recuperáveis e devem ser retentados sem destruir o token.
- Observado: qualquer 429/5xx apaga permanentemente o refresh token do Keychain, forçando re-login interativo no browser por um problema que se resolveria sozinho no retry. Secundário: o erro é rotulado `tokenExchangeFailed` mesmo na rota de refresh (:211), anulando a cópia de UI `.tokenRefreshFailed` (:26-27).
- (resolvedor) Correção [Auth/Sync worker]: fixed — `postToTokenEndpoint` agora classifica o não-200 num `TokenEndpointError { statusCode, isAuthoritativeAuthFailure }`: autoritativo só quando HTTP 401 ou (400 + corpo OAuth `error == "invalid_grant"`, via `parseOAuthError`). `refreshAccessToken` deleta o Keychain SÓ no caminho autoritativo; em 429/5xx (e erros de rede) mantém o refresh token, limpa apenas `cachedToken` e relança → o próximo poll agendado (cadência do scheduler) retenta sem re-login. Secundário resolvido: rota de refresh agora lança `AuthError.tokenRefreshFailed(statusCode:)` e a rota de exchange mantém `tokenExchangeFailed`. Backoff explícito não adicionado (a cadência do NSBackgroundActivityScheduler já espaça os retries). Sem mudança em Core. `swift build --target Auth` verde.
