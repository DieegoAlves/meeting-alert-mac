# F-051 — Reuniões de amanhã invisíveis na seção "Próximas" do menu bar

## F-051 | categoria: usabilidade | severidade: média | status: fixed
- Tela: Sources/MenuBar/MenuBarView.swift:36-39 — `upcomingToday` filtra `start < endOfToday`
- Passos: 1) Ter uma reunião marcada para amanhã de manhã. 2) Abrir o popover do menu bar. 3) A seção "Próximas hoje" usa `store.upcoming.filter { $0.start < endOfToday }`, descartando amanhã.
- Esperado: A história pede a seção "Upcoming" — reuniões futuras (incluindo amanhã) devem aparecer no popover.
- Observado: `EventStore.upcoming` inclui hoje+amanhã (Sources/Core/EventStore.swift:54-57: `$0.start > now && $0.start <= horizon` com horizon = fim de amanhã), mas `MenuBarView.upcomingToday` (linha 36-38) corta a fatia de amanhã com `endOfToday = startOfDay + 86400`. O histórico só mostra passado. Uma reunião de amanhã fica sem nenhuma superfície no popover.
- (resolvedor) Correção: Adicionada computed property `upcomingTomorrow` em MenuBarView (filtra `store.upcoming` com `start >= endOfToday`, limitado a `.prefix(5)`). Adicionada seção "Amanhã" no corpo da view após "Próximas hoje". Empty-state atualizado para incluir `upcomingTomorrow.isEmpty`. `computeTitle()` em MenuBarController já usa `store.upcoming.first` (que abrange amanhã), então o countdown no título já aponta para a primeira reunião de amanhã quando hoje está vazio — sem alteração necessária lá.
