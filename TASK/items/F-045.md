# F-045 — Servidor loopback aborta o sign-in na primeira conexão espúria ou parcial

## F-045 | categoria: funcional | severidade: média | status: fixed
- Tela: Sources/Auth/LoopbackRedirectServer.swift:88-127 (`receiveCode` resolve na PRIMEIRA conexão via OnceFlag), :98 (`receive` único), :135-138 (extractCode falha se não for GET/sem code), :65-78 (timeout de 5 min)
- Passos:
  1) Usuário inicia sign-in; o listener espera o redirect do browser.
  2) A PRIMEIRA conexão que chega dispara o `OnceFlag`/`resume` — pode ser um `GET /favicon.ico` do browser, um probe de reuso de conexão, ou um scan de LAN (ver F-043).
  3) `extractCode` nessa conexão retorna `.failure` ("não é GET" / sem code, :135-138) e resolve a continuation → `waitForCode` rejeita e todo o fluxo aborta, mesmo com o redirect real chegando milissegundos depois.
  4) Variante: `receive(minimumIncompleteLength: 1, maximumLength: 65536)` (:98) lê UMA vez; se a linha de request vier fragmentada em segmentos TCP, o primeiro chunk pode não conter o `GET /?code=…&state=…` completo → falha num redirect legítimo.
- Esperado: só o redirect válido (com `code` + `state` correto) conclui o fluxo; conexões espúrias/parciais são ignoradas até o timeout de 5 min.
- Observado: sign-in falha de forma intermitente ("OAuth redirect error") sem causa visível, exigindo nova tentativa.
- (resolvedor) Correção [Auth/Sync worker]: fixed — `receiveCode` reescrito. Novo `readRequest(on:buffer:...)` acumula bytes e chama `receive` repetidamente até a linha de request ter um CRLF (resolve fragmentação TCP); conexão que erra/fecha antes disso é cancelada e o listener SEGUE escutando. Nova classificação `classify(...) -> {code|csrf|ignore}`: só `.code` (code presente + state correto) resolve a continuation com sucesso; só `.csrf` (state presente e diferente) é falha dura; qualquer outra coisa (favicon, probe, sem code, sem state) é `.ignore` → fecha a conexão e continua até o timeout de 5 min existente. A continuation não é mais resolvida por conexão espúria/parcial. `swift build --target Auth` verde.
